# web-playground

화면에서 움직이는 효과를 경로별로 하나씩 모아 두는 Next.js 사이트다. 홈에는 효과마다 타일이 하나씩 있고, 타일의 버튼을 누르면 해당 경로로 이동한다.

## 들어 있는 것

| 경로 | 내용 |
|---|---|
| `/` | 효과 목록. 타일 배경에서 미리보기가 돈다. |
| `/fire` | 뜨개질 코 모양으로 그리는 불꽃놀이 |
| `/ascii` | 아스키 작품 목록 |
| `/ascii/<이름>` | 아스키 작품 하나를 전체 화면으로 |

### 불꽃놀이

하늘을 클릭하거나 터치하면 그 자리로 폭죽이 올라가서 터지고, 땅을 누른 뒤 글자를 쓰고 엔터를 치면 글자 모양으로 터진다. 글자는 40자까지 쓸 수 있고 "링크 복사"를 누르면 `?text=` 가 붙은 주소가 복사되어 그 주소를 연 사람 화면에서 같은 글자가 터진다. 상단 막대에서 실 색 19가지와 하늘 색 7가지를 고르고, 슬라이더로 자동으로 올라가는 폭죽의 양을 0에서 10 사이로 조절한다. 고른 값은 브라우저 `localStorage`에 남아서 다시 열어도 유지된다.

라이브러리 없이 Canvas 2D로 직접 그리며, 가로 7px 세로 6px짜리 코 격자에 입자를 찍는 방식이라 동시에 떠 있는 입자는 4,000개로 제한한다. 소리는 Web Audio로 합성하는데 브라우저 정책상 첫 클릭 이후에만 난다.

### 아스키

`/ascii`는 작품 카드가 나열되는 목록이고 카드를 누르면 전체 화면으로 열린다. 지금은 열 개가 있다.

| 경로 | 내용 |
|---|---|
| `/ascii/zed` | 2013년 챔피언스 서머 결승 5세트의 제드 맞대결을 18초로 다시 연출했다. 표식, 정화, 그림자 바꾸기, 점멸, 마무리 순서로 진행되고 왼쪽 위에 쓴 기술이 차례로 적힌다. |
| `/ascii/blackhole` | 빈 화면에 원이 그려지고 붉은 빛과 가스 원반이 차례로 생긴 뒤 7.8초에 번쩍이며 흐르기 시작한다. 그 뒤로는 9~18초마다 다시 번쩍인다. |
| `/ascii/namsan` | 남산타워를 바라보는 두 사람의 뒷모습. 산이 드러나고 타워가 아래에서 위로 그려진 뒤 전망대에 불이 들어오고, 7.3초부터 타워 둘레에서 불꽃이 터져 윤곽이 밝아진다. |
| `/ascii/starry-night` | 고흐의 「별이 빛나는 밤」. 달과 별이 먼저 켜지고 거기서부터 붓질이 번져 나가며, 붓 자국 3,200개가 소용돌이 열 개가 만드는 흐름을 따라 떠돈다. |
| `/ascii/galaxy` | 별 7,000개로 된 나선 은하. 한 점에서 별이 퍼져 나오며 팔이 풀리고 6.6초에 중심이 번쩍인다. 그 뒤로는 보는 기울기가 계속 바뀌고 별똥별이 지나간다. |
| `/ascii/tree` | 회전하는 트리. 아래에서 위로 쌓인 뒤 전구 170개가 아래부터 켜지고, 6.2초에 꼭대기 별이 켜지면서 눈이 내리기 시작한다. |
| `/ascii/fireworks` | 도시 위 불꽃놀이와 강물에 비친 모습. 처음 3초 동안 창과 강변에 불이 들어온 뒤에 쏘기 시작한다. |
| `/ascii/rose` | 줄기가 자라고 봉오리가 벌어지는 장미 (28초 주기). 다 피면 이슬이 반짝이고, 네 방울이 차례로 맺혔다가 떨어져 바닥에서 튄다. |
| `/ascii/bigbang` | 한가운데의 빛이 1.8초 동안 차오르다 번쩍이며 터지고 별 1,500개가 뻗어 나간다. |
| `/ascii/donut` | Andy Sloane의 donut.c 계산식을 옮긴 회전 도넛 |

도넛을 뺀 아홉 개는 같은 무대(`src/features/ascii/stage/AsciiStage.tsx`)에서 돈다. 장면이 매 프레임 글자 격자에 밝기와 색, 글자를 써 넣으면 무대가 Canvas에 칸 단위로 글자를 그리고, 같은 그림을 흐리게 한 겹 더 깔아서 빛이 번지게 한다. 칸 폭은 기본 6px(남산은 5px)이고 화면 폭에 따라 가로 56칸에서 200칸(남산은 240칸) 사이로 격자를 잡아 초당 30장을 그린다. 3D 장면은 점 구름을 투영해서 칸마다 가장 가까운 점을 남기고 밝기로 `.,:;-~=+*xo%#@` 중 한 글자를 고른다. 장미처럼 덩어리로 보여야 하는 물체는 점마다 조각 번호를 달아 두고, 빈 곳이나 더 뒤에 있는 다른 조각과 맞닿은 칸에 방향에 맞는 선 글자(`| / \ - _`)로 윤곽을 긋는다. 안쪽 칸은 밝기 네 단계마다 정해 둔 글자 묶음에서 고르고 초당 세 번 다른 글자로 바뀐다. 블랙홀은 점을 쓰지 않고 칸마다 그 자리 가스의 온도를 계산해서 글자와 색을 정한다. 무대는 앞 프레임을 45% 남겨 잔상을 만들고, 좁게 흐린 겹과 넓게 흐린 겹을 하나씩 얹어 빛이 번지게 한다. 색은 장면마다 두세 가지로 제한했고 블랙홀만 온도에 따라 붉은색에서 금색까지 다섯 단계를 쓴다.

점 구름을 글자 칸으로 옮기는 방식, 조각 경계의 윤곽선, 밝기별 글자 묶음, 빛살, 잔상과 번짐은 JIN2(@jin_22ee)의 Python 아스키 작품들(github.com/JIN2-ASCII/-JIN2-ASCII)에서 배운 기법이다. 블랙홀 장면은 그중 BLACK HOLE의 구성(그림자, 휘어 보이는 고리, 안쪽이 빨리 도는 원반)과 계산 방식을 따라 TypeScript로 다시 짠 것이다. 도입 순서(원, 빛, 원반, 번쩍임)도 원작을 따랐으며 원작의 저작권은 JIN2에게 있다.

제드 장면은 중계 화면을 옮긴 것이 아니고 알려진 순서에 맞춰 위치와 시간을 새로 짠 것이라 실제 경기와 초 단위로 맞지 않는다. 캐릭터 모습은 제드 인게임 모델 그림을 글자 칸 80 × 42로 줄여서 쓴다. 이 장면은 Riot Games의 "Legal Jibber Jabber" 정책에 따라 Riot Games 소유의 자산을 사용해 만들었고, Riot Games는 이 프로젝트를 보증하거나 후원하지 않는다.

## 실행

Node.js 20.9 이상과 pnpm이 필요하다.

```
pnpm install
pnpm dev
```

`http://localhost:3939`에서 열린다. 배포용 빌드는 `pnpm build` 후 `pnpm start`로 확인한다. 고친 뒤에는 `pnpm check`가 린트, 타입 검사, 테스트를 한 번에 돌린다.

## 구조

```
src/
├── app/           경로별 페이지
├── components/    공통 내비게이션, 홈 타일용 미리보기
└── features/
    ├── fire/      불꽃놀이 엔진(knitFireEngine.ts)과 화면
    └── ascii/     아스키 작품과 목록(asciiList.ts)
```

아스키 작품을 추가할 때는 `src/features/ascii/asciiList.ts`에 항목을 넣고 `src/app/ascii/<slug>/page.tsx`를 만든다.

## 한계

홈 타일의 불꽃 미리보기는 본편 엔진을 축소한 것이 아니라 따로 짠 간단한 버전이라 모양 불꽃이나 글자 불꽃은 나오지 않는다. 아스키 장면은 글자를 칸마다 `fillText`로 그리기 때문에 목록 페이지처럼 여러 장면이 한 화면에 동시에 보이면 저사양 기기에서 프레임이 떨어질 수 있다. 자동 테스트는 아스키 장면과 재생 상태 판정만 다루고(`pnpm test`), 불꽃놀이 엔진은 테스트가 없다. 동작은 데스크톱 Chrome에서만 확인했다.
